⚡ Google Sheets Doğrudan Yazma & Senkronizasyon Kurulumu

Bu panelden çektiğiniz kartvizitleri, inşaat projelerini, cari kartları ve stokları Google Drive / Sheets'e otomatik yazdırmak için 2 dakikalık kurulum adımı:

  1. Google E-Tablonuzu Açın
  2. Üst menüden Uzantılar > Apps Komut Dosyası (Extensions > Apps Script) seçin.
  3. Aşağıdaki hazır Google Apps Script kodunu yapıştırın ve Dağıt > Yeni Dağıtım (Deploy as Web App) deyin. (Erişim: "Herkes / Anyone").
  4. Oluşan Web App URL'sini aşağıdaki kutuya yapıştırıp "Kaydet"e basın.
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheetName = data.sheet || "Müşteriler";
    var row = data.row || [];
    
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(sheetName);
    if (!sheet) {
      sheet = ss.insertSheet(sheetName);
    }
    
    sheet.appendRow(row);
    
    return ContentService
      .createTextOutput(JSON.stringify({ status: "success", message: "Kayıt başarıyla eklendi." }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
